## 已知限制

- Android 普通图片目录跨重启访问受当前文件选择插件限制，0.3 仅承诺 Android ZIP/CBZ 闭环；
- Android 文件选择器将 ZIP 暂存到应用私有缓存；系统清理该副本后会进入来源不可用状态，可选择同指纹原 ZIP 重新定位并保留进度；
- 双页底栏显示当前跨页的起始页，例如 `1/20`、`2/20`、`4/20`，暂不显示 `2–3/20` 的范围文案；
- 不支持 RAR/7z、加密压缩包、动画图片语义或超预算容器；
- 不包含在线漫画源、站点规则、下载、番剧、账号或同步；
- Windows 暂无 MSI/MSIX，Android 暂未提供应用商店安装包。
