## 性能复测

固定 100 KiB、5 MiB、50 MiB TXT，各预热一次并正式运行三次。

| 50 MiB 指标 | v0.1.0 基线 | v0.2.0 候选复测 | 变化 |
|---|---:|---:|---:|
| 导入中位数 | 2808.843 ms | 1565.328 ms | -44.3% |
| 首次打开中位数 | 61.365 ms | 68.469 ms | +11.6% |
| 章节切换中位数 | 2.664 ms | 2.687 ms | +0.9% |
| RSS 峰值 | 221.95 MiB | 219.74 MiB | -1.0% |

首次打开增加约 7.1 ms，绝对值仍低于 0.1 秒；章节切换基本持平，导入和峰值内存改善，因此没有发现阻塞发布的性能回归。

报告：[`../performance/2026-08-09-txt-baseline.md`](../performance/2026-08-09-txt-baseline.md)。

## 已知限制

- 不支持 DRM、固定版式像素级还原、脚本、远程资源自动加载和复杂 MathML 完整呈现；
- 不支持不同内容文件在原作品内安全重解析；
- 超大 TXT 仍会缓存完整规范化文本；
- Windows 暂无 MSI/MSIX，Android 暂未提供商店安装包；
- 漫画、在线内容源、账号和同步不属于 MVP 0.2。

## 发布决定

最终结论：功能、数据、性能、双平台测试、Android 正式签名、构建哈希、干净环境复验与密钥异地备份均已完成。`v0.2.0` GitHub Release 已公开，并附带 Windows x64 便携 ZIP 与 Android 正式签名 APK。
