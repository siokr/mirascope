## 主要更新

- 本地漫画 ZIP/CBZ 与 Windows 图片目录导入、媒体库、详情和章节目录；
- 纵向连续、横向单页及封面单独成屏的横向双页阅读；
- 页级阅读进度、阅读方向与模式持久化；
- 有界内存/磁盘缓存、预加载、安全清理、重复检测与来源恢复；
- 保留并回归 TXT/EPUB 小说、书签、归档、重定位和删除闭环。

## 已知限制

- Android 0.3 仅承诺 ZIP/CBZ 漫画闭环，普通图片目录跨重启持久授权暂不支持；
- 双页底栏显示当前跨页的起始页，不显示页码范围；
- 不支持 RAR/7z、加密压缩包、在线内容源、下载、账号或同步；
- Windows 暂无 MSI/MSIX，Android 暂未提供应用商店安装包；
- schema v5 数据不支持降级给旧版本使用，更新前建议备份应用数据。
