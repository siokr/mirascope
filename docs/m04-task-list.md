## 阶段门槛

- 0.4 只增强本地能力，不引入账号、服务器、在线源或下载；
- 搜索、筛选和排序必须由仓储提供，页面不得加载全部媒体后自行扫描；
- 排序必须包含稳定的最终比较键，分页前后不得随机跳动；
- 标签、历史、编辑和恢复不得修改或删除用户原始媒体文件；
- 备份不得包含签名密钥、密码、在线凭据、缓存或临时文件；
- 恢复必须先校验并暂存，失败时保留现有数据库和派生内容；
- 每个 `done` 项必须留下自动化、基准、构建或人工验收证据；
- Windows 与 Android 的 TXT、EPUB、漫画、归档、重定位和删除闭环不得回归。
