# MVP 0.2 书签验收

## 结论

`M02-010` 书签闭环验收通过。TXT 与 EPUB 阅读位置均使用稳定语义定位，不依赖滚动像素。

## 功能范围

- 阅读页当前位置添加书签；
- 书签保存作品、章节、定位、标签与创建时间；
- 当前作品的书签列表；
- 点击书签跳回对应章节与位置；
- 软删除书签；
- 应用重启后保留书签；
- 删除媒体时由数据库外键级联清理所属书签；
- schema v2 升级到 v3 时保留既有书籍、进度和设置。

## 自动验证

- Dart 格式检查通过；
- Flutter 静态分析通过；
- 288 项自动化测试通过；
- 覆盖 schema v2 到 v3 迁移、书签增删查、跨作品章节拒绝、阅读页添加/列表/删除和原有路由回归；
- Android debug APK 构建、安装与启动通过。

## Android 人工验收

以下项目全部通过：

1. 在正文中间添加书签；
2. 在不同位置添加第二个书签；
3. 书签列表显示章节、百分比和时间；
4. 多个书签同时存在；
5. 点击书签跳回对应章节与大致位置；
6. 删除指定书签；
7. 完全关闭并重启应用后书签仍存在且可跳转；
8. 原有书籍、阅读进度和阅读设置没有回归。
