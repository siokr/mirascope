# mirascope MVP 执行清单

## 1. 文档职责

本文是当前开发任务和状态的单一信息源。版本范围以 `plan.md` 为准，实体和行为以专题规格为准。

当前执行版本：**MVP 0.1 — Windows 本地 TXT 阅读闭环**。

## 2. 状态与完成规则

- `planned`：范围明确，尚未开始；
- `in_progress`：正在实施；
- `blocked`：存在明确阻塞，并记录原因；
- `done`：交付物存在，验收已经执行并留下证据。

任务字段：

- **优先级**：P0 是版本必需，P1 可在不影响主链路时延后；
- **依赖**：必须先完成的任务 ID；
- **交付物**：具体代码、文档或测试；
- **验收**：可执行或可观察的完成条件。

不能以“代码写完”“看起来可用”直接标记 `done`。
