# mirascope MVP 执行清单

## 1. 文档职责

本文是当前开发任务和状态的单一信息源。版本范围以 `plan.md` 为准，实体和行为以专题规格为准。

当前执行版本：**MVP 0.1 — Windows 本地 TXT 阅读闭环**。

## 2. 状态与完成规则

- `planned`：范围明确，尚未开始；
- `in_progress`：正在实施；
- `blocked`：存在明确阻塞，并记录原因；
- `done`：交付物存在，验收已经执行并留下证据。

任务字段：

- **优先级**：P0 是版本必需，P1 可在不影响主链路时延后；
- **依赖**：必须先完成的任务 ID；
- **交付物**：具体代码、文档或测试；
- **验收**：可执行或可观察的完成条件。

不能以“代码写完”“看起来可用”直接标记 `done`。

## 3. MVP 0.1 任务

### M01-001 工程基础决策

- 优先级：P0
- 状态：planned
- 依赖：无
- 交付物：状态管理、路由、本地数据库和仓库结构的四份 ADR
- 验收：每份 ADR 包含备选方案、决策、代价和复核条件

### M01-002 Flutter 应用骨架

- 优先级：P0
- 状态：planned
- 依赖：M01-001
- 交付物：`app`、`core`、`shared`、`library`、`novel` 基础结构，替换默认计数器页面
- 验收：Windows 启动后可进入媒体库和设置页；默认示例代码和测试已移除

### M01-003 路由、主题与应用启动

- 优先级：P0
- 状态：planned
- 依赖：M01-002
- 交付物：路由配置、浅色/深色主题、启动初始化和依赖装配
- 验收：媒体库、小说详情、阅读器、设置之间可按预期导航；启动失败有可见错误

### M01-004 日志与统一错误模型

- 优先级：P0
- 状态：planned
- 依赖：M01-002
- 交付物：结构化错误类型、日志封装和用户错误映射
- 验收：日志不记录正文和完整敏感路径；小说规格中的导入错误有稳定代码

### M01-005 本地数据库与迁移

- 优先级：P0
- 状态：planned
- 依赖：M01-001、M01-002
- 交付物：MVP 0.1 所需表、约束、Repository 和 schema 迁移
- 验收：空库初始化、上一测试 schema 升级和失败回滚测试通过；模型符合 `docs/data-model.md`

### M01-006 媒体库

- 优先级：P0
- 状态：planned
- 依赖：M01-005
- 交付物：媒体库列表、空状态、最近打开排序和归档/恢复
- 验收：新增、重启、归档和恢复后状态一致；不会删除用户原文件

### M01-007 TXT 文件选择与指纹

- 优先级：P0
- 状态：planned
- 依赖：M01-004、M01-005
- 交付物：Windows 文件选择、文件校验、指纹和重复检测
- 验收：不存在、无权限、空文件、重复文件和同名不同内容得到规格规定的结果

### M01-008 TXT 编码与规范化

- 优先级：P0
- 状态：planned
- 依赖：M01-007
- 交付物：UTF-8、UTF-16、GB18030 识别、用户选择编码和文本规范化
- 验收：固定样例测试通过；无法可靠识别时进入预览选择，不静默乱码

### M01-009 章节识别

- 优先级：P0

- 验收：文件移动后保留媒体与进度；指纹不一致时不静默替换

- 依赖：M01-003 至 M01-015

### M01-017 性能基线

- 优先级：P1
- 状态：planned
- 依赖：M01-010、M01-012

### M01-018 演示与候选发布

- 优先级：P0
- 状态：planned
- 依赖：M01-015、M01-016、M01-017

- 验收：按 `docs/release-checklist.md` 完成检查；从干净环境复现核心演示路径

## 4. MVP 0.1 验收摘要

- [ ] Windows 上完成 TXT 导入到恢复进度的核心路径
- [ ] 支持编码和异常文件行为符合小说规格
- [ ] 重复导入、文件移动、数据库失败不造成数据丢失
- [ ] 自动化检查和 Windows 构建取得当次通过证据
- [ ] 性能基线、运行说明、演示和已知问题齐全
