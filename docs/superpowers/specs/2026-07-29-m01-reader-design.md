# M01-012 纵向滚动阅读器设计

## 1. 目标

读取 M01-010 生成的规范化 UTF-8 派生文本，按章节定位展示稳定纵向正文，提供目录、上一章、下一章和桌面键盘交互；切章失败时保留当前可读内容。

## 2. 数据读取

- `NovelReaderRepository` 查询媒体与按 `orderIndex` 排序的章节；
- 只接受 `content/<安全文件名>.txt` 引用；
- 派生全文使用严格 UTF-8 解码；
- 只接受 `txt-v1:<start>:<body>:<end>` 定位；
- 偏移按 Dart UTF-16 code unit 校验后切取正文；
- 对完整章节片段重新计算 SHA-256，和 `contentHash` 不一致则拒绝；
- 标题行不重复显示，正文从 `bodyStart` 开始。

## 3. 状态

应用控制器持有目录、当前章节、正文、加载目标和安全错误：

- 初次加载失败显示错误与重试；
- 切章时继续显示当前正文并显示加载状态；
- 切章失败保留当前章节和正文；
- 成功切章后滚动回顶部；
- 首章禁用上一章，末章禁用下一章。

## 4. 交互与布局

- 正文采用单一纵向 `SelectionArea + SingleChildScrollView`；
- 内容宽度限制在适合桌面阅读的范围，窗口缩小时保持边距和可滚动；
- AppBar 显示当前章节并提供目录；
- 支持方向键左右、PageUp/PageDown 切章；
- 目录抽屉按顺序展示并标记当前章节；
- 本阶段使用固定排版 token，持久化阅读设置属于 M01-013。
