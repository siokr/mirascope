# M01-009 TXT 章节识别设计

## 1. 目标

把 M01-008 产出的规范化全文解析为有序章节，覆盖规格要求的常见中英文独占行标题；无法可靠识别时回退为单一“正文”，保证全文可读且不写数据库。

## 2. 范围

本阶段包含：

- 独占一行的中文章、节、回、卷标题；
- 独占一行的 `Chapter + 阿拉伯数字` 英文标题；
- 标题长度限制；
- 标题、正文和原始 UTF-16 字符偏移；
- 标题识别依据；
- 开篇正文保留；
- 空章节抑制；
- 无标题回退。

本阶段不包含数据库写入、内容哈希、派生文件、重新解析映射或界面。

## 3. 输入和偏移

输入必须是 `DecodedTxt.text` 的规范化文本，换行只使用 `\n`。解析器不再改变文本。

偏移采用 Dart `String` 的 UTF-16 code unit 索引，能够直接用于 `substring`：

- `startOffset`：该内容单元在全文中的起点；
- `endOffset`：该内容单元在全文中的排他终点；
- `headingStartOffset`：识别出的标题行起点；回退正文没有该值；
- `bodyStartOffset`：标题行终止换行之后的正文起点。

每个结果的 `[startOffset, endOffset)` 连续覆盖全文，不丢弃序言、被抑制的空标题或尾部字符。

## 4. 标题规则

候选行先移除行首尾空白再匹配，内部字符保持原样。标题最多 80 个 Unicode 码点。

中文序号允许阿拉伯数字和常用中文数字：

- `第 + 序号 + 章/节/回/卷`；
- `卷 + 序号`。

编号和量词之间可有空白，后续标题必须以空白分隔。英文仅识别不区分大小写的 `Chapter + 阿拉伯数字`，后续标题同样以空白分隔。正则锚定整行，因此正文句子中出现“第几章”不会切章。

## 5. 章节边界和空章节

- 首个标题前有可读内容时，生成题为“正文”的开篇单元；
- 每个有效标题从其标题行起，到下一个保留标题之前结束；
- 若一个标题到下一个标题之间只有标题和空白，该标题不单独成章；其文本仍由相邻单元覆盖；
- 若全部候选都被抑制，生成覆盖全文的单一“正文”；
- 结果顺序与原文一致，标题保留原始字符，仅移除外围空白。

## 6. 识别依据

结果以稳定枚举记录 `chineseOrdinal`、`chineseVolume`、`englishChapter` 或 `fallback`。M01-010 可据此生成 `sourceLocator`，但本阶段不定义数据库格式。
