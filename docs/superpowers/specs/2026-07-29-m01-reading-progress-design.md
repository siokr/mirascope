# M01-014 阅读进度持久化与恢复设计

## 1. 目标

保存当前章节和章节内字符偏移，滚动时节流写入，切章和生命周期变化时立即刷新；重新打开时恢复语义位置，并保证旧异步写入不能覆盖更新位置。

## 2. 定位

- `contentUnitId` 标识章节；
- `locator` 使用 `char-v1:<UTF-16 offset>`；
- `fraction` 只用于展示和损坏定位的安全回退；
- UI 按滚动比例估算章节 UTF-16 字符偏移，不保存像素；
- 恢复时优先解析字符偏移并换算为当前排版的滚动比例。

字符偏移限制在 `[0, chapterText.length]`。非法定位回退到合法 fraction；两者都无效则回到章节开头。

## 3. 写入

- 滚动变化使用 750ms trailing debounce，期间新位置覆盖旧待写位置；
- 切章前刷新旧章节，切章成功后立即保存新章节开头；
- 应用进入 inactive、paused、detached 或页面释放时尝试刷新；
- 写入串行执行，同一会话的 revision 单调递增；
- Repository 只接受“当前 revision + 1”，冲突时读取较新记录，旧请求不得覆盖。

## 4. 恢复

1. 查询作品进度；
2. 若原 `contentUnitId` 仍存在，打开该章节；
3. 若章节不存在，回退第一章；重新解析映射属于 M01-015；
4. 读取章节成功后暴露待恢复字符偏移；
5. Widget 首次布局后按正文长度换算滚动比例并跳转。

恢复失败不阻断正文阅读，只从安全章节开头继续。
