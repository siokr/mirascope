# M01-013 阅读设置设计

## 1. 目标

为纵向阅读器提供字号、行距、浅色、深色和护眼主题；调整即时预览并持久化，重启后按作品设置、全局设置、程序默认值的顺序恢复。

## 2. 有效值与回退

- 字号范围：12–36，默认 18；
- 行距范围：1.2–2.4，默认 1.6；
- 主题：`system`、`light`、`dark`、`sepia`；
- 阅读模式：MVP 0.1 仅 `vertical`。

保存前严格拒绝非有限值、越界数值和未知主题。读取历史或外部损坏数据时不抛给界面：每个无效字段独立回退到下一层，最终回退程序默认值。

## 3. 继承和保存

有效设置按字段解析：

```text
作品设置 -> 全局设置 -> 程序默认值
```

阅读器面板保存作品级覆盖。调整时先更新内存预览，再异步写入 Repository；写入失败恢复上一个有效值并显示安全错误。恢复默认会保存所有字段为空的作品记录，使其重新继承全局设置。

## 4. 界面

- 阅读器 AppBar 提供设置按钮；
- BottomSheet 包含字号和行距滑块、四种主题选择、恢复默认；
- 正文背景和文字颜色随主题即时变化；
- `sepia` 使用暖色低对比背景作为护眼主题；
- 设置面板和正文在小窗口中均可滚动，不发生溢出。
