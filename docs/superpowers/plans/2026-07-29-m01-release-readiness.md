# M01-018 MVP 0.1 候选发布收口计划

## 任务 1：校准项目门面

- 将版本改为 `0.1.0+1`；
- 更新包描述；
- 重写 README 的状态、能力、架构、质量证据和运行入口；
- 扫描并移除“初始模板、尚未开发”等过期表述。

## 任务 2：建立演示和已知问题

- 编写核心演示脚本及测试数据要求；
- 编写已知问题、影响、绕行和处理计划；
- 明确不同内容原位重解析、本机 MSVC 和实机验收限制；
- 不使用商业小说或私人文件。

## 任务 3：建立候选发布记录

- 复制并逐项执行发布检查清单；
- 记录提交、命令、自动检查、Windows 构建和性能基线；
- 未验证项保持未勾选并说明阻塞；
- 不创建标签、Release 或安装包附件。

## 任务 4：质量和敏感信息审计

- 格式检查、静态分析、全量测试；
- GitHub Actions Windows release 构建；
- 扫描 Token、密码、私人绝对路径和过期状态；
- 检查 `pubspec.lock` 与提交一致。

## 任务 5：Windows 人工验收

- 修复或绕过本机 MSVC HostX86/HostX64 选择异常；
- 启动 release/debug Windows 应用；
- 执行演示路径、重启恢复和错误路径；
- 获取真实截图或短演示；
- 从干净环境复现。

## 任务 6：收口决策

- 人工验收未完成：M01-018 标记 `blocked`，候选说明列出限制；
- 人工验收完成：补全证据后标记 `done`；
- 是否添加许可证、推送 `main`、创建标签和 GitHub Release 均由用户明确决定。
