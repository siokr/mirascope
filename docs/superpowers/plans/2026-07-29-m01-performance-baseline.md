# M01-017 TXT 性能基线实施计划

## 任务 1：实现可复现基准工具

- 新增 `tool/txt_performance_baseline.dart`；
- 流式生成 100 KiB、5 MiB、50 MiB 自建样本；
- 使用独立子进程隔离每次测量；
- 覆盖完整导入、打开和章节切换；
- 记录耗时、章节数和 RSS。

## 任务 2：验证基准工具

- 为样本生成、结果中位数和报告格式补充自动化测试；
- 确认输出不包含临时路径或正文；
- 运行现有格式、分析和测试门槛。

## 任务 3：生成正式基线

1. 使用 `dart build cli` 将工具和 SQLite 原生资产构建为 AOT bundle；
2. 每个样本预热一次；
3. 每个样本正式运行三次；
4. 保存 JSON 和 Markdown；
5. 核对样本大小、哈希、章节数、机器信息和版本；
6. 如实记录失败或测量限制。

## 任务 4：同步项目状态

- 更新 `docs/quality-strategy.md` 的基准运行入口；
- 更新 `docs/mvp-task-list.md` 的当次证据；
- 更新 `HANDOFF.md`；
- 不在第一份基线中虚构性能阈值。
