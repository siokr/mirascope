# M01-010 TXT 原子导入实施计划

> 对应设计：`docs/superpowers/specs/2026-07-29-m01-atomic-import-design.md`

## 任务 1：schema v2

1. 为导入记录加入 `text_encoding`。
2. 允许失败记录不引用已回滚媒体。
3. 生成并提交 v2 schema helper。
4. 测试空库、v1 到 v2、约束和失败迁移回滚。

## 任务 2：领域与仓库事务

1. 扩展 `ImportRecord` 编码和可空媒体语义。
2. 严格验证成功 TXT 与失败记录。
3. 在数据库事务提交前提供派生文件提升点。
4. 测试数据库写入、提升失败和整单回滚。

## 任务 3：派生文本存储

1. 定义平台无关的暂存句柄接口。
2. 实现应用数据目录内 UTF-8 暂存、原子重命名和幂等清理。
3. 测试原文件不变、失败清理和最终引用。

## 任务 4：导入协调用例

1. 串联候选重复检查、解码、章节识别和聚合构造。
2. 生成章节定位、哈希和内容引用。
3. 处理编码选择、重复、解析失败与存储失败。
4. 失败时写入无媒体外键的稳定失败记录。

## 任务 5：装配与验收

1. 通过 Riverpod 装配 ID、时钟、派生存储和完整用例。
2. 运行代码生成、schema 生成、格式化、静态分析和全量测试。
3. 审计日志、用户原文件、事务与孤立文件。
4. 在 Windows 工具链恢复前保留实机导入验收阻塞。
