## 2. Windows 核心闭环

- [ ] 从普通图片目录导入，封面、章节、页数和自然排序正确；
- [ ] 从 ZIP/CBZ 导入，结果与目录来源一致，重复导入不产生第二本；
- [ ] 详情页选择不同章节，能从对应页面进入阅读器；
- [ ] 纵向连续、横向单页、左右/右左翻页、目录跳转、缩放和键盘操作正常；
- [ ] 退出和重启后恢复到对应章节与近似页面，阅读偏好仍保留；
- [ ] 移动来源后显示来源不可用；选择同一内容重新定位后恢复，进度不丢失；
- [ ] 归档、恢复、永久删除和删除后重新导入正常，原目录或压缩包未被删除；
- [ ] 设置页清理漫画缓存后书籍与进度仍存在，再次打开能重新读取页面；
- [ ] 损坏图片只影响对应页面；整章不可读时可重试或返回目录；
- [ ] 缩窄窗口、放大窗口和切换横竖比例时无溢出、卡死或不可达操作。

## 3. Android 核心闭环

- [ ] ZIP/CBZ 文件选择、导入、详情、目录和阅读正常；
- [ ] 纵向/横向阅读、手势返回、系统 Home/最近任务、缩放和方向切换正常；
- [ ] 退出、切后台和重启后进度及阅读偏好恢复；
- [ ] 重复导入、来源移动后的同指纹重新定位、归档/恢复/永久删除正常；
- [ ] 清理缓存后媒体、进度和原文件保留，页面可重新生成；
- [ ] 竖屏书架卡片、详情、目录、阅读底栏和设置弹层无 `OVERFLOWED`；
- [ ] TXT 与 EPUB 各导入一本并打开阅读，确认 0.2 核心路径未回归；
- [ ] Android 普通目录跨重启访问不作为 0.3 承诺：当前插件不保留 SAF URI 权限，界面不得误导为已支持。

## 4. 安全与失败路径

- [ ] 取消文件/目录选择时不报错、不新增条目；
- [ ] 路径穿越、重复路径、加密、损坏或超预算压缩包被整体拒绝；
- [ ] 隐藏文件和非图片被忽略，损坏图片不会形成半完成导入；
- [ ] 错误提示不包含完整私人路径、图片内容、原始异常或堆栈；
- [ ] 所有失败和清理操作均不修改或删除用户原始来源。

## 6. 验收发现

- 2026-08-15，候选 `b8212ed` 使用真实 ZIP 漫画发现未声明 UTF-8 的 GBK/GB18030 内部章节名显示为 `µÚ01»Ø`；外层标题、封面、页数、阅读和重复导入正常。
- 已增加未声明 UTF-8 文件名的严格 GB18030 解码与字节往返校验，纯 ASCII、已声明 UTF-8、安全路径和容器预算规则不变；专项测试及 377 项全量测试通过，等待新候选包实机复测。
- 中文章节名在新候选包中复测为“第01回”，兼容缺陷关闭。随后阅读验收发现详情页缺少恢复已保存页码的入口；已新增与小说一致的“开始阅读”主入口，无章节参数进入时恢复保存位置，目录章节仍从章首打开，等待新候选包复测。
- Windows 来源移动、同指纹重新定位、进度保留、缓存清理、归档/恢复/永久删除、原文件保留及重新导入 1—9 项通过。按验收反馈新增横向双页：封面单页，之后 2—3、4—5 成对展示，左右阅读方向同步调整页内顺序，模式写入 schema v5 偏好。
- 双页首轮实机验收发现分页重叠为 `1+2`、`2+3`，造成第 2 页跨屏重复；已修正为 `1`、`2+3`、`4+5`，并增加第一屏不存在第 2 页的自动化断言，等待新候选复测。
- 2026-08-15：人工复测发现“从右到左 + 横向双页”会把后一页重复到左右两侧；原因是原地反转页索引时覆盖了尚未读取的元素，已改为生成独立反转列表并补组合回归测试，等待复测。
