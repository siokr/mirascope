# MVP 0.2 Windows EPUB 人工验收

候选提交：以提供验收包的 GitHub Actions 运行所示提交为准。

## 准备

1. 使用本次提交生成的 Windows Release 整目录，不要只复制 exe；
2. 运行 `dart run tool/create_epub_acceptance_fixtures.dart`；
3. 使用 `build/acceptance/epub` 内项目自建的 EPUB 2 和 EPUB 3 样本；
4. 保留至少一本已验证的 TXT 小说，用于回归。

## 核心闭环

1. 在书架点击“导入 EPUB”，选择 `mirascope-epub2.epub`；
2. 确认自动读取书名并进入详情，章节目录顺序正确；
3. 进入阅读器，确认标题和正文可见，返回、目录、左右方向键、上下滚动键正常；
4. 滚动到明显位置，返回并重新进入，确认章节和近似位置恢复；
5. 重启应用，再次确认进度恢复；
6. 导入同一个 EPUB，确认打开已有作品，不生成重复条目；
7. 对 `mirascope-epub3.epub` 重复步骤 1—3；
8. 打开原有 TXT，确认详情、阅读、进度和返回仍正常。

## 来源与媒体库

1. 关闭应用，将已导入的 EPUB 移动到另一个目录；
2. 启动后打开详情，确认提示来源不可用，但派生章节仍可阅读；
3. 点击“重新定位源文件”，选择移动后的同一 EPUB，确认提示恢复；
4. 再次移动文件，尝试选择另一个 EPUB，确认应用拒绝替换并保留当前阅读内容和进度；
5. 归档 EPUB，确认可恢复；再次归档并永久删除，确认可以重新导入；
6. 确认以上操作都不会删除原始 EPUB。

## 错误与界面

1. 将普通 ZIP 或文本文件改名为 `.epub` 后尝试导入，应显示安全中文错误和处理建议；
2. 取消文件选择不显示错误；
3. 缩窄和放大窗口，确认两个导入按钮、目录和阅读正文无溢出；
4. 错误提示不得包含完整私人路径、正文、异常或堆栈。
