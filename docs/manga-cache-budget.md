# 漫画缓存预算基线

更新时间：2026-08-15

## 默认值

- 相邻页预加载：当前页前后各 2 页；
- 应用管理的压缩图片内存缓存：64 MiB；
- 可删除磁盘缓存：512 MiB；
- 淘汰：内存与磁盘均优先淘汰最久未使用项；
- 缓存键：媒体 ID、导入时固化的图片内容哈希和字节数。

## 容量依据

导入安全上限允许单张图片最大 64 MiB，但常规本地漫画页通常远低于该值。以偏保守的 4 MiB 压缩图片作为容量基线，前后各 2 页加当前页需要约 20 MiB；64 MiB 内存预算提供约 3 倍余量，同时不会让应用自行持有无限压缩字节。512 MiB 磁盘预算可容纳约 128 张 4 MiB 页面，足够覆盖多章短期阅读局部性，又保持为可随时删除的派生数据。

Flutter 自身的解码图像缓存不计入上述压缩字节预算；M03-012 的 Windows/Android 实机基准仍需分别记录进程峰值，并可据此下调默认值。未经双平台数据，不上调当前预算。

## 已验证行为

- 命中缓存不会重复读取原目录或 ZIP/CBZ；
- 磁盘项损坏或与内容哈希不符时删除并回源；
- 写入使用临时文件后原子改名；
- 快速翻页会让旧预加载代次失效，失效结果不写缓存；
- 当前页读取不等待相邻页预加载；
- 清理缓存不涉及媒体记录、阅读进度、缩略图或用户原文件。
