# mirascope 本地漫画阅读规格

## 1. 范围

本地漫画属于 Version 0.3。该版本只处理用户拥有的本地目录或受支持压缩包，不包含在线漫画源、站点规则、云端下载或番剧。

## 2. 支持输入

- 本地目录：一个作品可包含章节子目录，或将根目录视为单章节；
- 压缩包：首期评估 ZIP/CBZ；其他格式只有在依赖、许可证和跨平台行为确认后才加入；
- 图片：首期评估 JPEG、PNG、WebP，实际支持列表必须由解码测试确认；
- 加密压缩包、损坏中央目录、路径穿越和超大展开必须拒绝。

ZIP/CBZ 的导入安全上限为：压缩包不超过 2 GiB、条目不超过 20,000、单条目不超过 64 MiB、总展开量不超过 2 GiB、单条目压缩比不超过 200 倍。容器仅按需读取条目，不把整个压缩包展开到磁盘；读取时还必须校验实际输出大小和 CRC。以上是导入防护上限，不代表图片缓存或预加载预算。

原文件的身份、重复检测、移动和删除行为沿用 `docs/data-model.md`。

## 3. 排序和章节

- 默认采用自然排序，使 `2.jpg` 位于 `10.jpg` 之前；
- 章节目录同样自然排序；
- 可忽略隐藏文件和明确不支持的非图片文件；
- 图片顺序必须在导入时固化，不能因系统遍历顺序变化；
- 空章节不写入活动 `ContentUnit`；
- 用户调整顺序后保存显式顺序，不再依赖文件名重新计算。

## 4. 导入事务

导入先扫描并验证文件清单，再在临时区域生成缩略图和章节清单，最后通过事务写入 `MediaItem`、`LibraryEntry`、`ContentUnit` 与 `ImportRecord`。

任何失败都必须回滚不完整实体并清理临时文件，不修改或删除用户原始漫画。

## 5. 阅读模式

Version 0.3 支持：

- 纵向连续滚动；
- 横向单页翻页；
- 从左到右或从右到左的翻页方向。

双页模式不是 Version 0.3 完成条件，可在桌面体验验证后单独加入。

进度使用章节 ID、页索引和页内位置，不保存单纯像素坐标。改变窗口尺寸或阅读模式后仍应恢复到同一页附近。

## 6. 预加载与缓存

- 预加载窗口以当前页为中心，优先前后相邻页面；
- 内存缓存和磁盘缓存分别限制；
- 快速翻页时取消已经无价值的低优先级解码；
- 原始文件、派生缩略图和可删除缓存必须分区；
- 清理缓存不能删除漫画记录和进度；
- 缓存键至少包含文件身份和变化标识，源图片变化后不得继续展示旧缓存。

具体窗口和容量先通过基准确定，不在缺少数据时填写固定数值。

## 7. 错误行为

- 单张图片损坏：展示占位和错误信息，允许继续阅读后续页面；
- 整章无可读图片：章节不可进入，并提供重新扫描；
- 原文件丢失：保留媒体和进度，提供重新定位；
- 图片解码内存不足：取消非必要预加载并允许重试；
- 压缩包不安全或不受支持：拒绝导入，不做部分解压。

日志不得记录图片内容或完整敏感路径。

## 8. 验收

- 目录和 ZIP/CBZ 样例按稳定顺序导入；
- `2.jpg`、`10.jpg` 的自然排序正确；
- 纵向和横向模式切换后仍能恢复到对应页面；
- 单张损坏图片不阻断后续阅读；
- 文件移动后可重新定位并保留进度；
- 缓存清理不删除原始文件、媒体记录和进度；
- 大章节的导入、首屏和连续阅读结果按质量策略记录。

## 9. 在线源进入条件

在线漫画源必须作为独立版本评审，并先明确内容来源、站点条款、扩展接口、凭据处理、缓存权限和失效策略。它不能以 Version 0.3 的“补充功能”形式直接加入。
