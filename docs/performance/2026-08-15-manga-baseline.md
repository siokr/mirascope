# mirascope 漫画性能基线

> 本报告是 Version 0.3 的首次漫画基线，用于后续同环境回归比较，不代表已经冻结性能阈值。

## 环境

- 日期：2026-08-15；
- Git 提交：`54c0dbe`（基准工具尚未提交时的工作树）；
- 系统：Microsoft Windows 10 专业版 `10.0.19045`；
- CPU：12th Gen Intel Core i5-12450H，12 个逻辑处理器；
- 内存：15.71 GiB；
- Flutter：3.44.8 stable；Dart：3.12.2；
- 模式：`flutter test` 的 JIT 测试进程，使用真实 Flutter 图片解码器；
- 预热：1 次；正式运行：3 次；报告中位数。

## 样本与边界

- 私有本地兼容性样本，仅用于本机测量，图片内容、标题和路径均未提交；
- 85 章、891 页，JPEG/PNG/WebP 扫描规则与正式导入一致；
- 图片总字节数：255,433,911（243.60 MiB）；
- 每轮完整扫描均重新枚举、读取、哈希并真实解码全部图片；
- 首页与连续读取每轮使用全新磁盘/内存缓存；连续读取取前 50 页；
- 不包含文件选择器、数据库事务、缩略图、窗口首帧和 GPU 解码纹理内存。

## 结果

| 指标 | 正式运行 1 | 正式运行 2 | 正式运行 3 | 中位数 |
| --- | ---: | ---: | ---: | ---: |
| 891 页扫描与图片验证 | 15,271.660 ms | 15,165.746 ms | 14,955.565 ms | 15,165.746 ms |
| 冷缓存首张读取 | 6.829 ms | 6.021 ms | 5.686 ms | 6.021 ms |
| 连续读取 50 页 | 500.780 ms | 463.145 ms | 436.293 ms | 463.145 ms |
| 连续读取平均每页 | 10.016 ms | 9.263 ms | 8.726 ms | 9.263 ms |
| 50 页磁盘缓存 | 13.35 MiB | 13.35 MiB | 13.35 MiB | 13.35 MiB |

测试进程正式轮次观测到的最高 RSS 为 203,931,648 字节（194.48 MiB）。该值包含 Flutter 测试框架与前序轮次残留，不是 Windows/Android release 应用的独立峰值，因此只作为保守观测值，不冻结为内存阈值。

## 结论

- 三次完整扫描离散很小，中位数约 15.17 秒，基准具有可比较性；
- 冷缓存首张读取中位数约 6.02 ms，连续 50 页读取中位数约 463 ms；
- 50 页压缩字节缓存约 13.35 MiB，符合 64 MiB 内存与 512 MiB 磁盘上限的设计方向；
- Android 16 模拟器的 20 页真实漫画导入、连续/单页/双页阅读、方向切换与缓存重建已完成人工验收，未观察到卡死或内存不足；
- 本轮只建立基线。后续在相同环境重复测量后，才决定是否冻结回归比例；GPU 纹理峰值仍需 profile/release 工具补充时另行记录。

原始数据见 [`2026-08-15-manga-baseline.json`](2026-08-15-manga-baseline.json)。运行入口：

```powershell
$env:MIRASCOPE_MANGA_BENCHMARK_SOURCE='<directory-or-archive>'
$env:MIRASCOPE_MANGA_BENCHMARK_KIND='directory' # 或 archive
flutter test tool/manga_performance_baseline_test.dart --reporter expanded
```
